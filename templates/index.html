Project Overview

This assignment demonstrates the integration and deployment of a pre-trained Hugging Face model (DistilBERT) for Fake News Detection. The model is fine-tuned on a real-world dataset and deployed using Flask for easy access via REST API endpoints.

🤖 Model Details

  • Base Model: DistilBERT (Hugging Face)
  • Task: Binary Text Classification
  • Classes: Fake News / Real News
  • Max Sequence Length: 256 tokens
  • Fine-tuning Epochs: 3
  • Training Samples: 5,000

How It Works

  1. Input: User provides news text
  2. Tokenization: Text is tokenized using DistilBERT tokenizer
  3. Processing: Tokens are fed to the fine-tuned DistilBERT model
  4. Classification: Model outputs probabilities for Fake/Real classes
  5. Prediction: Highest probability class is selected as prediction
  6. Response: Result returned with confidence scores
